# Manali Sharad Kadam | Portfolio

Personal portfolio of Manali Sharad Kadam, a B.Sc. Computer Science graduate from Pune, India, looking for an entry-level software developer role.

## Sections
Hero, About, Technical Skills, Featured Projects, Education, Internship, Certifications (with certificate previews), Strengths and Contact.

## Built with
- React 18
- Tailwind CSS
- Lucide icons
- Plain CSS animations, with `prefers-reduced-motion` respected

The whole site is a single `index.html` file. It loads React, Tailwind and the icons from CDNs, so it needs an internet connection to display.

## Run locally
Open `index.html` in a browser.
